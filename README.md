# ВГУИТ Помощник

Неофициальное Android-приложение для студентов ВГУИТ: расписание занятий,
рейтинг успеваемости и карта корпусов с построением маршрута.

> Приложение не является официальным продуктом вуза. Данные берутся с открытых
> страниц ВГУИТ и могут отличаться от официальных.

## Что умеет

**Расписание студентов**
- загрузка xlsx с сайта факультета, разбор в фоновом изоляте;
- таблица по дням с числителем и знаменателем, подгруппами и объединёнными ячейками;
- выбор курса и одной группы в боковом меню; выбранные курс и группа запоминаются;
- кэш на устройстве: расписание открывается без интернета.

**Расписание преподавателей**
- список преподавателей и их пары с сайта `timetable.vsuet.ru`;
- числитель и знаменатель склеиваются в одну карточку, если пара совпадает;
- пары разных предметов в одно окно показываются рядом, в общей рамке;
- фильтр по дню недели; выбранный преподаватель и день запоминаются.

**Рейтинг**
- факультеты, группы, предметы и ведомости с `rating.vsuet.ru`;
- «моя зачётка» по номеру зачётки: оценки, итоги по контрольным точкам;
- кэш ведомостей и выбор факультета/группы между запусками.

**Карта**
- планы шести этажей с масштабом в метрах (305 px ≈ 55 м);
- кратчайший маршрут по A* с учётом лестниц и стоимости подъёма;
- поиск аудитории, выбор точки тапом по плану, оценка времени в пути;
- переключение этажей, иконки лестниц, подписи без наложений.

**Уведомления**
- фоновая проверка расписания по будильнику Android (работает при закрытом приложении);
- раз в день или раз в неделю, в выбранное время, для выбранных групп;
- пуш, если расписание изменилось; кэш обновляется всегда.

**Обновления**
- проверка последнего релиза на GitHub при запуске и по кнопке в настройках;
- окно с версией, размером и списком изменений;
- кнопка «Скачать» открывает APK в браузере, установку выполняет система;
- приложение не запрашивает право устанавливать другие APK — поэтому
  Google Play Protect не показывает предупреждение.

## Установка

1. Откройте [Releases](../../releases) и скачайте последний `app-release.apk` (раздел Assets).
2. Разрешите установку из этого источника, когда система спросит.
3. Обновления приложение предложит само — кнопка «Скачать» откроет файл в браузере.

**Требования:** Android 7.0+ (minSdk 24).

### Про предупреждение Google Play Protect

Начиная с версии **1.0.2** приложение не запрашивает разрешение
`REQUEST_INSTALL_PACKAGES`: обновление скачивается через браузер, а установку
выполняет система. Поэтому характерного предупреждения «приложение может
устанавливать другие приложения» больше нет.

В версиях **1.0.0 и 1.0.1** это разрешение было — там Play Protect мог показать
предупреждение при установке. Это не сообщение о найденном вирусе, установка
проходила через «Подробнее» → «Всё равно установить».

Само APK по-прежнему подписано собственным сертификатом разработчика, а не
ключом Google Play, поэтому система может спросить подтверждение установки
из неизвестного источника — это обычное поведение Android для приложений
вне магазинов.

Подлинность APK можно проверить самостоятельно — см. раздел «Проверка подписи».

## Откуда данные

| Что | Источник |
|---|---|
| Расписание студентов | `vsuet.ru/images/student/schedule/*.xlsx` |
| Расписание преподавателей | `timetable.vsuet.ru` |
| Рейтинг и ведомости | `rating.vsuet.ru/web/ved` |
| Карта | `assets/map/*.json` и `*.svg` |

Парсеры рассчитаны на текущую вёрстку сайтов. Если вуз поменяет разметку или
структуру файлов, соответствующий раздел перестанет обновляться — приложение
покажет ошибку и продолжит работать на кэше.

## Сборка из исходников

**Окружение:** Flutter 3.47.6+ (Dart 3.13.5), JDK 17, Android SDK с платформой 37.

```bash
flutter pub get
flutter run                 # отладка
flutter build apk --release # релиз
```

Для релизной сборки нужен ключ подписи: создайте `android/key.properties`
(в git не попадает, см. `.gitignore`):

```properties
storeFile=../vguit-release.jks
storePassword=…
keyAlias=…
keyPassword=…
```

Без этого файла debug-сборки работают как обычно, а `--release` падает
с понятным сообщением — чтобы случайно не опубликовать APK на debug-ключе.

Подробности выпуска версий и настройки автообновления — в
[UPDATE_SETUP.md](UPDATE_SETUP.md).

## Проверка подписи

Все релизы подписаны одним ключом. Отпечаток сертификата (SHA-256):

```
f9fe365156562e8b5cd97591d81ece2e145329aaacbc0a483d7907bd19d13d8b
```

Проверить скачанный APK:

```bash
apksigner verify --print-certs app-release.apk
```

Отпечаток должен совпадать. Если не совпадает — файл скачан не из этого
репозитория.

## Тесты

```bash
flutter analyze   # статический анализ, 0 замечаний
flutter test      # 76 тестов
```

Покрыто: парсер расписания (включая пары только по чётной неделе), парсер
преподавателей (ФИО, склейка недель, порядок групп), каталог групп факультета,
данные карт и алгоритм маршрута (сверка с Дейкстрой), преобразование координат,
кэш, настройки уведомлений, сравнение версий обновления.

## Структура проекта

```
lib/
  models/            модели данных, преобразование координат карты
  services/          сеть, парсеры, кэш, маршруты, уведомления, обновления
  screens/           экраны и их секции
  widgets/           общие диалоги и плашки ошибок
  background/        точка входа фонового изолята (будильник)
assets/map/          планы этажей: JSON-граф и SVG
android/             настройка Android: подпись, разрешения
tool/map_check.dart  проверка данных карты и маршрутов без запуска приложения
```

Проверка карты после правок JSON:

```bash
dart run tool/map_check.dart
```

## Ограничения

- Проверка обновлений и фоновые проверки расписания — только Android.
- Обновление скачивается вручную: приложение открывает ссылку в браузере,
  файл попадает в «Загрузки», установку подтверждает система.
- Метры и время в пути рассчитаны по масштабу плана и средней скорости пешехода,
  это оценка, а не точный расчёт.
- Приложение не заменяет официальное расписание и зачётную книжку.
